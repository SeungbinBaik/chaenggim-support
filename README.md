# 챙김 — support & privacy

Google Play 가 요구하는 개인정보처리방침 URL 과 지원 URL 용 정적 페이지.

- 고객 지원: https://seungbinbaik.github.io/chaenggim-support/
- 개인정보처리방침: https://seungbinbaik.github.io/chaenggim-support/privacy.html

앱은 이 페이지를 실행 중에 불러오지 않는다(인터넷 권한 없음). 설정의 「웹에서 보기」만 브라우저로 연다. 원본은 앱 저장소의 `docs/public/`.
